# Ollama Local Provider

This directory owns the Ollama-specific local-provider surface for `local_llm`.

## What lives here

- startup and install helpers for the repo-local Ollama runtime
- the provider-owned runtime directory with `bin/ollama`
- the validated alias `Modelfile.qwen2.5-0.5b-nb`
- the generated local nanobot config for the Ollama path

## Install and start

```bash
bash local_llm/local_provider_ollama/install_ollama.sh
export PATH=/home/wubinyi/workspace/embed_nanobot/local_llm/local_provider_ollama/runtime/bin:$PATH
ollama serve
```

## Validated local config

Use:

```text
local_llm/local_provider_ollama/runtime/local_ollama.json
```

That config is generated by:

```bash
/home/wubinyi/miniforge3/envs/embed_nanobot/bin/python local_llm/scripts/render_agent_configs.py
```

## Local validation

Direct probe:

```bash
curl -s http://127.0.0.1:11434/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen2.5:0.5b-nb",
    "stream": false,
    "messages": [{"role": "user", "content": "Reply with exactly OLLAMA_OK and nothing else."}]
  }'
```

Smoke path:

```bash
bash local_llm/scripts/run_agent_smoke.sh --mode local
```
